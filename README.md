# Game Xếp Khối Vuông

Sẵn sàng triển khai bằng GitHub Pages.

## Cách triển khai
1. Tạo repository mới tên `xep-khoi`.
2. Tải 4 file `index.html`, `manifest.json`, `service-worker.js`, `icon.svg` lên nhánh `main`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn **main** và **/(root)** rồi Save.
6. Địa chỉ dự kiến:
   `https://truongtho6699.github.io/xep-khoi/`

Trên iPhone: mở bằng Safari → Chia sẻ → Thêm vào Màn hình chính.
Trên Android: mở bằng Chrome → Cài đặt ứng dụng/Thêm vào màn hình chính.
